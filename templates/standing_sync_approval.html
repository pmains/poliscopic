What you are being asked to allow

Every day, after the scrape and the entity pipeline have finished and passed their checks, copy the day's data from the development database to the public production database. Instead of asking you each morning, this proposal would let that routine copy happen on its own — but only while every mandatory gate below passes, and only for the exact tables listed further down.

If any gate fails, the copy must not run, and a failure must not quietly use up one of the permitted runs. This is a bounded permission: it expires, it has a maximum number of successful runs, and it can be revoked.
